## 6. RAG Pipeline – How It Works
1. **Ingestion** – Load document, split into overlapping chunks, embed each chunk, store in FAISS.  
2. **Query** – Embed user question, retrieve top‑k similar chunks, construct prompt (`system + retrieved chunks + question`), send to **OpenRouter gpy‑oss‑120b:free**, return answer.

### Why RAG (not fine‑tuning)?
* Instant support for new documents  
* Answers stay grounded in source text → fewer hallucinations  
* Cheaper & faster than training a bespoke model  
* Ability to show source chunks for transparency
